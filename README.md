## Main Features
<a id="main-features"></a>

### Core Functionality
- **Disk Cloning** — Clone entire hard drives or individual partitions quickly and efficiently, making data transfer and backups hassle-free.
- **Multiple File System Support** — Compatible with various file systems like EXT2, EXT3, EXT4, FAT, NTFS, and more, ensuring versatility across different environments.
- **Network Backup** — Save disk images locally or on network storage, allowing users to manage backups in their preferred location.
- **Bootloader Restoration** — Easily reinstall bootloaders like Grub and Syslinux, streamlining the recovery process after cloning.
- **LVM2 Support** — Clone Logical Volume Management (LVM) setups, providing advanced users with additional flexibility for disk management.

### Advanced Capabilities
- **ISO Image Distribution** — The software is distributed as an ISO image that can be utilized as a LiveCD, enabling users to boot Clonezilla directly from a disk or USB drive.
- **Multiple Device Restoration** — Restoration of disk images can occur on multiple local devices simultaneously, improving efficiency in managing backups across systems.
- **User-Friendly Documentation** — Comprehensive help and support documentation is available, guiding users through the cloning process with ease.
- **Offline Mode** — Clonezilla can function offline, allowing full backup capabilities without the need for an active internet connection.
